# Translation

Сайт перевода карты Котомышь использует Firebase Realtime Database.

## Права доступа

- Вошедшие пользователи по умолчанию работают как переводчики. Они читают фразы, сохраняют индивидуальные и групповые переводы, добавляют комментарии и меняют собственное отображаемое имя.
- Редакторы с `users/<uid>/role = "editor"` также подтверждают и восстанавливают переводы, редактируют оригиналы, меняют активность фраз и импортируют WTS.
- Администраторы с `users/<uid>/canManageDb = true` назначают роли и восстанавливают резервную копию базы. Обычный профиль не может изменить этот флаг или роль.

Правила в `database.rules.json` проверяют права на сервере. Переводчик не может удалить фразу, изменить оригинал, подтвердить перевод или изменить чужие комментарии. Изменённый перевод теряет подтверждение, а предыдущая подтверждённая версия сохраняется.

Все изменения содержимого сайта выполняются одним атомарным обновлением с увеличением `metadata/revision` на единицу. Проверка версии защищает от записи поверх параллельных изменений. Старые записи без версии поддерживаются как версия 0. Комментарии добавляются с отдельными ключами, чтение поддерживает и прежние массивы.

Существующие роли хранятся в `users`. Назначать администраторов следует через доверенную Firebase Console или Admin SDK. Первый администратор также создаётся через эти инструменты.

## Проверка и публикация

Для проверок нужны Node.js 24.12+, Java 21+ и Firebase CLI.

```sh
npm ci
npm test
npm run test:rules
```

Проверки правил используют локальный эмулятор с проектом `demo-translation`. Они проверяют разрешённые действия, попытки повышения прав и реальные функции сайта.

После публикации совместимой версии сайта применить правила к рабочему проекту можно командой

```sh
firebase deploy --only database --project translatorapp-6fd48
```

После обновления правил открытые вкладки сайта нужно перезагрузить.
